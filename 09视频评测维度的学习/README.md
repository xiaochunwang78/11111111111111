# 09 视频评测维度的学习

> 本稿是官方资料调研与学习大纲，先供检查，暂不展开完整教程与验收阈值。
> 调研日期：2026-10-26。用户所说的“Dxo”和“Em Test”，本稿分别按 DXOMARK 与 Imatest 理解。
> 范围：以手机、相机的拍摄视频质量为主；音频、直播网络和长期录制可靠性列为选学扩展。

## 一、调研结论：两者怎样做视频测试

### 1. DXOMARK：评价协议、实验室测量与实景感知评价

- 围绕实际拍摄用途，结合受控实验与实景感知评价，形成属性评价及分数；评的是成像链路的最终表现。[D2]
- 官方主摄视频页面明确列出七个属性：曝光、颜色、自动对焦、纹理、噪声、伪影、防抖。[D1]
- 同时关注静态结果和随时间的变化；其视频长焦部分另外说明变焦与多摄过渡的评估。[D1]
- 用受控照明、图卡和运动装置等获得可比结果；不能只用一帧截图判断整段视频。
- Analyzer/AZ 是测量工具体系；公开榜单协议、商业实验室服务及软件能力的范围并不完全相同。[D3][D4]
- 不将旧版文章的权重、设备条件或样本数量直接当作当前统一规则；本稿不推测未公开的评分公式与阈值。

### 2. Imatest：图卡、受控条件与指标分析工具

- 通过指定图卡、光照、距离、取景与 ROI 获得可重复测量，按问题选择分析模块，而非套用一份固定的视频总分榜单。[I8]
- 对视频可抽取单帧或帧组进行分析；时域噪声需要多帧样本。[I1][I3]
- 3A 时域分析把相关指标绘成时间曲线：AF 可用 SFR 中的清晰度指标；AE 可用亮度或曝光误差；AWB 有相应的颜色分析方法。[I2][I4]
- 配合运动装置与计时设备，可研究防抖、运动模糊、滚动快门与帧率等问题。[I5][I6]
- 必须区分“软件直接输出的指标”“需要配套硬件的实验”和“需要另做的实景主观评价”。具体功能取决于软件版本、模块及设备。

### 3. 两者在本学习模块中的作用

| 对照项 | DXOMARK | Imatest |
|---|---|---|
| 学习重点 | 属性分类、用户场景、感知评价及综合判断 | 指标原理、图卡选择、受控测量及时间曲线 |
| 实验组织 | 实验室与实景相互补充 | 依据测量目的配置模块、图卡及装置 |
| 结果形式 | 属性评价、公开报告与评分；工具也可输出测量结果 | 指标、图表、测量结果；综合判定需另定规则 |
| 本稿使用边界 | 公开评分属性与商业测量能力分别标注 | 单帧测量与视频时域功能分别标注 |

## 二、视频评测维度汇总与建议章节

说明：下表是对公开资料的归纳与学习编排，不是任一机构的原始目录。子项是拟学习内容；一行的来源不代表其中每个子项都是该机构独立评分项。

| 拟定章节 | 要学习的内容 | 来源与归类 |
|---|---|---|
| 01 曝光与视频 AE | 主体亮度、曝光误差；明暗切换的响应、收敛、过冲、稳定性；人脸与背景的取舍 | DXOMARK 七属性之一；Imatest AE 时域分析 [D1][I4] |
| 02 色彩与视频 AWB | 白点、肤色、饱和度、色彩还原；光源切换、混合光、白平衡收敛与颜色跳变 | DXOMARK 七属性之一；Imatest AWB 分析 [D1][I2][I4] |
| 03 视频 AF 与主体跟踪 | 合焦准确性、合焦与恢复时间、持续跟焦、主体切换、拉风箱、过冲；区分焦点呼吸与焦点振荡 | DXOMARK AF；Imatest SFR 时域分析；DXOMARK 商业测量亦列出合焦时间及呼吸 [D1][I2][D3] |
| 04 清晰度与纹理 | SFR/MTF、锐度与真实细节；运动纹理、锐化光晕、涂抹、清晰度随时间变化 | DXOMARK Texture；Imatest 图卡分析与 SFR 时间曲线 [D1][I2][I8] |
| 05 空间噪声与时间噪声 | 亮度/色度噪声、固定图样；多帧统计、空间/时间噪声区别，以及降噪与细节取舍 | DXOMARK Noise；双方公开时域噪声资料 [D1][D3][I3] |
| 06 动态范围、层次与 HDR 视频 | 高光和暗部、可用动态范围的定义；HDR 运动重影、亮度映射稳定性；输出格式与显示核验单列 | DXOMARK 商业 HDR 测量及 Imatest 通用图卡测量；学习上单列，非 DXOMARK 第八属性 [D3][I8] |
| 07 视频防抖 | OIS/EIS/IBIS 基础；静态手持、行走、跑步、摇摄；残余抖动、跳变、形变、裁切与细节损失 | DXOMARK 七属性之一；Imatest 防抖实验方案，需区分锐度改善与完整视频稳定性 [D1][I5] |
| 08 运动还原与滚动快门 | 曝光运动模糊、时域拖影、融合重影；倾斜、果冻、读出时间及与防抖的联动 | 双方公开运动/计时测量能力；从伪影等内容中拆出学习 [D3][I6] |
| 09 帧率、帧间隔与连续性 | 实际帧率、缺失帧、重复帧、节奏、卡顿；区分采集异常与播放器异常 | DXOMARK 商业计时项目、Imatest 配套设备；时间戳与播放定位为工程补充 [D3][I6] |
| 10 抗频闪与条带 | 灯光频率、PWM、曝光和读出的关系；整帧亮度变化、横向条带及频闪测试条件 | DXOMARK 商业计时项目、Imatest 频闪资料；需控制光源 [D3][I7] |
| 11 光学、采样与处理伪影 | 畸变、暗角、色差、眩光、鬼影、锯齿、摩尔纹、伪色、光晕及其动态变化 | DXOMARK Artifacts；Imatest 通用图像质量分析，具体子项分别选方法 [D1][I8] |
| 12 视频变焦与多摄切换 | 连续变焦平滑性；切摄时曝光、白平衡、焦点、构图、细节和防抖一致性 | DXOMARK 官方视频变焦说明；本稿独立编排 [D1] |
| 13 编码、HDR 输出与播放链路 | 块效应、振铃、色带、纹理损失；码率、位深、色彩解释、元数据、转码与显示 | Imatest 官方讨论视频压缩影响；完整输出链路为工程扩展，不冒充双方独立评分项 [I9] |
| 14 特殊视频模式（选学） | 人像虚化、美颜、夜景、慢动作、延时；重点检查边缘、主体和处理效果的跨帧一致性 | 按设备功能补充；不据本轮资料认定为双方统一独立评分项 |

AWB 不只检查色温数值，也要看偏绿/偏品红及主体颜色；清晰度曲线变化也不自动证明 AF 故障。曝光、降噪、防抖和编码都可能影响结果。

## 三、每个专项以后按什么结构展开

1. **评测目标**：这个维度解决什么问题，用户能看到什么现象。
2. **必要原理**：只讲支持判断所需的成像、控制或信号知识。
3. **主观观察项**：正常播放看什么，慢放和逐帧用于定位什么。
4. **客观指标**：定义、单位、ROI、时间窗口、计算条件与局限。
5. **测试搭建**：图卡、光源、运动/计时装置、距离、姿态与设置。
6. **实景测试**：人物、纹理、逆光、低照及运动场景。
7. **动态过程**：起始状态、变化触发点、响应、收敛、恢复及稳态。
8. **证据与判定**：原片、曲线、重复次数、波动范围；阈值注明依据。
9. **混淆与定位**：如何区分相似现象，如何设计对照和回归。
10. **来源与工具边界**：哪项来自官方协议、哪项可由工具直接测量、哪项为自行设计。

## 四、横向测试条件与覆盖矩阵

这些是各维度共同使用的测试条件，不与 AF、防抖等并列为质量属性。

| 条件轴 | 建议覆盖 |
|---|---|
| 光照 | 明亮、室内、低照；色温与光谱、混合光、频闪光源 |
| 场景明暗 | 均匀照明、逆光、高光、暗部及大光比 |
| 主体 | 人脸/肤色、细纹理、纯色、反光和运动主体 |
| 距离与动作 | 近远切换、接近/远离、横移、遮挡与重新出现 |
| 相机运动 | 三脚架、静态手持、行走、跑步、摇摄及启停 |
| 拍摄模式 | 分辨率、帧率、焦段、摄像头、SDR/HDR、防抖模式 |
| 状态与重复 | 软件版本、温度、录制时长；重复次数与样本保留 |
| 观察链路 | 原片、解码器、播放器、显示器、色彩管理与观看条件 |

测试矩阵不要求穷举所有组合；后续按工作目标选择典型场景、边界条件与高风险交叉项，明确未覆盖范围。

## 五、工具、实验与结果表达的大纲

- 图卡怎么选：斜边、纹理、色卡、灰阶/动态范围图卡各自解决什么问题。
- 运动与时间怎么控制：移动图卡、抖动装置、LED 计时与事件触发。
- 单帧、帧组与时间曲线：各自能回答什么，抽帧会漏掉什么。
- 主客观怎么结合：曲线异常对应哪个可见现象，指标改善是否伴随副作用。
- 参考视频类指标的边界：PSNR、SSIM、VMAF 等不能替代 AF、防抖和完整相机评测；如后续学习，另查原始资料。
- 结果模板：条件 → 操作 → 现象 → 指标/曲线 → 重复性 → 结论与局限。

## 六、按方向选学的扩展范围

- 完整录像产品：收音、音画同步、录制启停、文件完整性、长录发热、降帧与功耗。
- 直播/视频通话：端到端延迟、网络适应、卡顿、恢复及声画体验。
- 专业制作：Log/RAW 视频、调色空间、输出接口与时间码。

以上作为未来扩展方向，不宣称已完成相关标准调研，不据此增加当前核心学习负担。
