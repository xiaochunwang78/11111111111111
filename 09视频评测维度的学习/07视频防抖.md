# 07 视频防抖

> 目标：评估视频是否稳定、自然、清楚，并能定位“画面不抖但细节糊”“走路边缘拉扯”“停止摇摄后回弹”等问题。本文的用例是工程学习设计，不代表厂商内部评分公式。

## 1. 手机防抖需要同时评价什么

OIS 通过镜头或传感器的物理运动补偿部分相机运动；EIS 通过图像变换、裁切及相关估计减小输出运动。手机可能组合使用多种机制。仅从设置中关闭“视频防抖”，不能假定所有物理补偿都关闭，必须查具体模式或可获得的元数据。

最基本的四项是：**残余运动、画面形变、细节保留、构图/视角代价**。还要评价有意摇摄能否平顺跟随、动作启停时是否跳变。EIS 使帧间位置稳定，不会自动恢复曝光期间已经模糊的纹理。三星官方 Super Steady 说明了更大校正余量与裁切的关系，也提示低照与运动模糊的限制；其中示例比例不能泛化到所有 Galaxy 机型。[1]

## 2. 指标与条件

| 指标 | 测量思路 | 容易误用之处 |
|---|---|---|
| 残余平移/旋转 | 静态背景特征跟踪，报告像素或归一化位移、角度与时间曲线 | 不追踪运动主体；不同视角下像素幅度不能直接比 |
| 补偿比例 | 受控输入下比较输出角运动与输入角运动 | 输入需同步标定；接近零输入时比例不稳定 |
| 振动频谱 | 对残余运动曲线做频谱分析，区分步频与高频颤动 | 窗口、采样率、去趋势方式必须一致 |
| 画面形变 | 分区跟踪，观察边缘与中心运动是否一致 | 单个全局变换可能掩盖局部拉扯 |
| 细节损失 | 同照度、快门、视角下比较静态与运动纹理 | AF、降噪、编码、裁切放大都会影响锐度 |
| 裁切与视角 | 固定机位拍标记板，比较保留范围和动态变化 | “防抖更稳”可能同时更窄，需一起报告 |
| 启停过渡 | 摇摄开始/停止后位移、回弹、稳定时间 | 有意运镜应被允许，不能把零运动作为唯一最优 |

可定义教学用残余角运动 RMS：$RMS=\sqrt{\frac1N\sum_t(\theta_t-\bar\theta)^2}$，但只适合指定静止保持段；摇摄段应先建立期望轨迹。这个统计量不是通用防抖总分。

## 3. 实验室与实景如何搭配

Imatest 的公开方案把抖动装置和图卡锐度分析相结合，适合测补偿对细节的影响。[2] 完整视频体验还需加入残余运动、形变、构图和动作过渡。

AOSP 的预览防抖文档明确关联视角与防抖功能验证；Camera ITS 还使用运动装置及陀螺仪数据检查防抖行为。[3][4] ITS 是平台功能验证，不能替代原生相机的画质评分。测试名、支持条件与阈值绑定 Android/CTS 版本；不要把旧脚本中的门槛直接复制到新项目。

产品层面先测原生相机，记录机型、版本、焦段、分辨率/帧率、HDR、普通/增强防抖。接口层面另测 Camera2/CameraX，记录请求值、实际能力和输出流。两组结果若不同，不能未经证据就说“同一算法故障”。

## 4. 可复现测试矩阵

用例中的速度与路线需自行标定；入门可先重复三次，再按项目要求增加样本。

| 用例 | 条件与动作 | 关注与证据 |
|---|---|---|
| ST-01 静态手持 | 对远景建筑持机不动，分别主摄/长焦 | 高频微抖、漂移、细节波动；原片和稳定背景轨迹 |
| ST-02 行走 | 固定路线、步频与持机高度，正向/侧向走 | 步频起伏、边缘拉扯、地平线；路线和重复样本 |
| ST-03 跑步 | 同一路线普通与增强防抖对照 | 大幅运动补偿、视角代价、糊帧与跳帧 |
| ST-04 摇摄启停 | 标记起终点，匀速摇摄后保持 | 跟随迟滞、突然释放、回弹、停止漂移 |
| ST-05 低照行走 | 重复白天路线，测量照度并记录快门信息 | 背景稳定但纹理拖尾、时域涂抹；不只看轨迹 |
| ST-06 近远景混合 | 近处栏杆与远处建筑同时入画，横移 | 视差导致的局部形变与主体扭曲 |
| ST-07 预览与成片 | 外部相机记录手机预览，同时保存原片 | 视角、延迟与稳定性是否一致；不把屏录当原片 |

## 5. 缺陷拆解

“忽清忽糊”：先看焦点是否变化，再看快门与纹理方向；低照下与步频同步的模糊常需要检查曝光期间运动，但不能据此排除 AF 或时域降噪。“果冻”：比较稳定背景的行间倾斜与局部拉伸，结合第 08 章检查滚动快门；开关防抖时若摄像头或快门同时变化，不能把差异全部归给 EIS。

“视角变窄”：Apple 官方说明增强防抖会略微放大取景，因此裁切可能是设计行为；仍需测试是否符合产品说明以及变化是否平顺。[5] “三脚架漂移”则需要在固定机位复测，确认风振、桌面震动与环境变化后，再检查控制漂移。

## 6. 练习与交付

选主摄和长焦各拍静态手持、行走、摇摄三类。输出一页评价：残余抖动、局部形变、清晰度、裁切、过渡各自怎样；附两个最差时间段与发生频率。不要仅以“开启后抖动少”给出总优胜结论。

## 7. 学习资料

1. [Samsung CamCyclopedia：Super Steady](https://r2.community.samsung.com/t5/CamCyclopedia/Super-Steady/ba-p/13968541)：官方专家栏目；读裁切余量及低照限制。它是技术说明，不是公开验收协议。
2. [Imatest：Image Stabilization](https://www.imatest.com/solutions/image-stabilization/)：读抖动生成、图卡与锐度比较，明确其覆盖范围。
3. [AOSP：Camera preview stabilization](https://source.android.com/docs/core/camera/camera-preview-stabilization)：读预览和非 RAW 流的功能支持与验证入口。
4. [AOSP：Camera ITS tests](https://source.android.com/docs/compatibility/cts/camera-its-tests)：搜索 `sensor_fusion`、`preview_stabilization`、`video_stabilization`；按目标 Android 版本阅读。
5. [Apple：视频录制设置](https://support.apple.com/en-ie/guide/iphone/iphc1827d32f/ios)：查增强防抖、运动模式低光设置，转换为具体机型测试条件。
6. [DXOMARK：Camera 测试范围](https://www.dxomark.com/what-we-test-camera/)：看防抖属性与手持/行走条件；不要自行推测未公开权重。
